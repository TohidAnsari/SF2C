# 2.5D Hybrid Engine & 3D Assets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Shadow Fight 2 Web Edition into a 2.5D hybrid fighting experience by integrating real CC0 3D assets (Torii Gate, Dojo Weapon Racks, Paper Lanterns, Katanas, Daggers) into a high-performance WebGL background and interactive 3D Armory Inspector, while maintaining authentic 2D silhouette martial arts combat in the foreground.

**Architecture:** A layered 2.5D architecture where a Three.js WebGL canvas renders behind the primary 2D combat canvas (`gameCanvas` & `lobbyCanvas`). The 3D camera synchronizes with the 2D camera framing and player position, providing dynamic depth perspective. In the Armory, an interactive 3D WebGL Inspector allows players to examine weapons and equipment in full 3D with specular lighting.

**Tech Stack:** Three.js (r128), GLTFLoader, WebGL, Canvas 2D, Web Audio API, Vanilla JavaScript.

**Spec:** Feudal Japan 2.5D hybrid arena, CC0 3D models from `3dassets-mcp`, interactive 3D Armory Inspector, weapon inertia physics.

## Global Constraints
- Standalone execution: all assets, scripts, and models must function seamlessly without broken dependencies.
- Zero regression on existing 8-way combat, IK kinematics, procedural audio, or tournament ladder progression.
- Graceful fallback: if WebGL is unavailable, the 2D procedural canvas backgrounds continue to operate seamlessly.

---

## File Structure & Responsibility

- `lib/three.min.js`: Three.js core library (standalone bundle).
- `lib/GLTFLoader.js`: Three.js GLTF/GLB loader.
- `assets/3d/`: Local directory housing downloaded CC0 `.glb` models:
  - `torii.glb`: Torii Gate (Feudal Japan Castle Town)
  - `dojo_wall.glb`: Dojo Wall With Weapon Rack
  - `lantern.glb`: Round Japanese Paper Lantern
  - `katana.glb`: Katana with curved blade & hilt
  - `katana_saya.glb`: Katana Scabbard
  - `dagger.glb`: Tactical Kunai/Dagger
- `js/three_scene.js`: 2.5D WebGL Scene Orchestrator:
  - Manages 3D lighting (ambient, sunset directional, warm point lights on lanterns).
  - Synchronizes 3D camera pan/tilt with 2D fighter positions.
  - Sways lanterns with wind physics.
  - Manages the Armory 3D Equipment Inspector (orbit controls, item swapping, metallic sheen).
- `js/renderer.js`: Updated to layer seamlessly with the 3D WebGL canvas.
- `js/dojo.js`: Updated to coordinate with the 3D Dojo environment.
- `js/armory.js`: Updated to trigger 3D equipment inspection upon clicking armory items.
- `index.html`: Updated with WebGL background canvas and 3D Inspector modal.
- `css/style.css`: Updated with styling for the 3D inspector viewport and 2.5D canvas layering.
